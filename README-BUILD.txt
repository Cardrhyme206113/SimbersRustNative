SIMBERS NATIVE: LOCAL WINDOWS BUILD

1. Install Rust (rustup.rs) and Visual Studio Build Tools with "Desktop development with C++".
2. Extract this ZIP and double-click BUILD-ON-WINDOWS.cmd (or run it from a terminal).
3. The compiled application will appear as SimbersNative.exe in this folder.
4. If compilation fails, upload build-log.txt to ChatGPT so errors can be fixed.

The Rust toolchain downloads code dependencies during BUILD only. The EXE does not fetch assets at runtime; the human-flow corpus is compiled into it. This is a native prototype, not yet a feature-for-feature replacement for the HTML Simbers7 build. This source has not successfully compiled in this environment; compile errors may need resolving.
